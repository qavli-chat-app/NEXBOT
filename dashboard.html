Bot admin setup

WhatsApp does not let a bot grant admin to itself. The connected account is the bot identity: if this same number is already admin, refresh to re-check identity matching. If it is a different number, an existing group admin must promote the connected bot number in WhatsApp.

The selected member is promoted immediately when WhatsApp accepts the request and NEXBOT is already a group admin.

Moderation controls

Settings persist to /data/bot-state.json. Link, spam and blocked-word logic uses actual incoming WhatsApp events.

Strict moderation applies to every group automatically. NEXBOT must be a group admin to delete violating messages; it will still issue a warning if deletion is unavailable.

Permissions checklist

Bot needs group-admin permission to delete messages or manage members.
The panel key authorizes dashboard API calls; keep it private.
